## Notes

- A note is a Markdown file. **The title field is the file name**; renaming the title renames the file.
- **⌘N** new note · **⇧⌘N** new notebook (a folder; notebooks can be nested).
- **Tags** and **status** (Active, On hold, Completed, Dropped) sit in the bar above the editor. **⌥⌘P** pins a note to the top.
- Drag a note onto a notebook in the sidebar to move it.

## Writing

- Type **/** for the insert menu: headings, lists, task lists, quote, code block, table, divider, callouts (Note, Tip, Important, Warning, Caution), math, Mermaid diagram, link to note, image, highlight, footnote, date and time — and **Claude**.
- Type **:** and a word for emoji (`:fire`), and **```** for a code block with language suggestions.
- **⌘B** bold · **⌘I** italic · **⌘E** inline code · **⇧⌘H** ==highlight== · **⌥⌘K** link · **⌘↵** tick a checkbox.
- Paste or drag pictures straight in (iPhone HEIC photos are converted). Paste a web link and VibeNote fetches its title.
- The preview shows tables, clickable checklists, math, Mermaid diagrams, callouts and footnotes.

## Links between notes

- `[[Note title]]` links to a note (type `[[` for suggestions). `[[Note#Heading]]` jumps to a heading; `[[My API#GET /users]]` to an endpoint of an API spec.
- ⌘-click a link in the editor to follow it. A note shows **🔗 Linked from** when other notes link to it.

## Finding things

- **⌘K** for everything; **⇧⌘F** to search. Filters: `tag:guide`, `book:Ideas`, `status:active`, `title:plan`, `is:pinned`, `-tag:old`.
- **⇧⌘O** jumps to a heading in the current note. **⌃- / ⌃⇧-** go back and forward between notes.
- The ⇅ button above the list sorts and **groups** it (by notebook, tag or type). Click a heading to fold it; ⌥-click folds everything inside.

## History and safety

- **⌥⌘Y** — Version History: every version says **who** made it (You, Claude, Confluence); **Changes** shows exactly what changed. You can restore any version.
- Deleted notes go to **Trash** (in the sidebar) and can be restored.
- Export a note as **HTML** or **PDF** (⇧⌘E), or print it (⌘P).
