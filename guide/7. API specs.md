OpenAPI / Swagger specs are pages of their own, with live documentation beside the YAML.

- **⌥⌘N** (or **+** next to **APIs**) creates a spec. Write YAML on the left; the docs update on the right.
- Switch the docs between **Swagger** and **Reference** (a clean, modern look with code samples) at the top right.
- **Try it out** / **Test Request** sends real requests from your Mac.
- A ```yaml OpenAPI block inside any note gets an **⚡ API docs** button; **Save as API spec** turns it into its own page.
- Link to an endpoint from any note: `[[My API#GET /users/{id}]]`.
- In a spec, **/claude** writes YAML for you ("add a POST /orders endpoint").
