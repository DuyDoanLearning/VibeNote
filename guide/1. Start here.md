VibeNote keeps a piece of work in one place: **notes and documents, the code, diagrams, and your Claude chats** about them. Everything is plain files in your notes folder, so nothing is locked in.

## The window

- **Left: the sidebar.** All Notes, Inbox, **Projects**, Notebooks, **Confluence**, APIs, **Diagrams**, Status and Tags.
- **Middle: the note list.** Group it by notebook, tag or type with the ⇅ button. Labels show what each item is: **Note**, **Confluence**, **API**.
- **Right: the editor.** Edit, Split or Preview (⌘1 / ⌘2 / ⌘3).
- **Far right: Claude** (⌘J) and **comments** (⇧⌘M) when you open them.

## Five things to try first

1. **⌘K** — the command palette. Type anything: a note title, `>` for commands, `#` for headings.
2. **⌘N** — a new note. Type the title in the big field at the top; that's also its file name.
3. Type **/** in a note — a menu of things to insert (headings, tables, checklists, callouts, diagrams…).
4. **⌘J** — open Claude next to your note and ask it something.
5. Pause at the end of a sentence — Claude suggests how to continue in grey. **Tab** accepts.
