A **project** gathers one piece of work: its notebook, the documents that belong to it (also Confluence pages, API specs, other notebooks), a code folder with one or many repositories, diagrams and several Claude chats.

## The home page

Click a project in the sidebar's **Projects** section:

- **What's new since you last looked** — new commits, changed files, chats that need you.
- **Brief** — what every new chat reads first: goal, key documents, what each repository does, decisions, open questions. **Update with Claude** lets Claude draft it.
- **Documents** — the project's notes plus what you added with **Add documents…** (tick folders or single pages; a folder includes everything inside it).
- **Diagrams** — the project's draw.io files (right-click to delete).
- **Code** — each repository with its branch, uncommitted files, last commit, **Changes** and **Chat**.
- **Chats** — this project's chats, and earlier chats from the same code folder.

## Several chats per project

- **New chat** starts another one; switch between them in the Claude panel. A chat can focus on one repository and has its own model and permission mode.
- Chats keep working in the background; the project shows when one needs your OK.

## Coding layout — **⌥⌘J**

- The chat in the middle, the code or document beside it.
- **Changes** shows what's not committed yet (or any recent commit) as a diff. **Click a line to comment**, then send all your comments to Claude as one review.
- Files Claude mentions open in a read-only **file viewer**, with **Open in VS Code**.

## Notes

- **New project** with the **+** next to Projects. A project is just a notebook with a "Project brief" note, so it travels with your notes; the link to the code folder is set per Mac.
