Claude can help right inside a note, without opening the chat.

## /claude — ask Claude to write

- Type **/claude** on a new line (or press **⇧⌘J**) and ask: "a table comparing X and Y", "a checklist for the release", "a summary of this note"…
- Claude's text appears as it's written. **Insert** adds it; type a new request to change it ("shorter", "in Vietnamese").
- **Select text first** and press ⇧⌘J to have Claude rewrite it — then **Replace**.
- Claude knows the note, its recent edits and — shown under the box — **your Claude chat about this project**. Click that line to leave the chat out.

## Grey suggestions while you write

- Pause at the end of a line and Claude suggests how to continue, in grey.
- **Tab** accepts · **Esc** dismisses · keep typing to ignore it (typing the same words keeps the rest).
- It never suggests inside code blocks, tables or API specs. Turn it off or change its model in **Settings → Claude**.

## Comments and @Claude

- Select text and click the purple **Comment** pill (or **⌥⌘M**). The comments panel is **⇧⌘M**.
- Write **@Claude** in a comment and Claude replies in the thread. If it suggests a change you see **before → after** and choose **Accept** or **Reject**.
- On Confluence pages you can **Post to Confluence** to share a comment with colleagues.

## Choosing models

**Settings → Claude** has a model for each job:

- **Claude panel** — the main chat (also `/model` in the panel)
- **Comments & suggested fixes** — pick **Haiku** to make @Claude replies quicker and cheaper
- **/claude writing**
- **Inline suggestions** — Haiku by default (fast and small)

Smaller models answer faster and use less of your plan; bigger ones write better.
