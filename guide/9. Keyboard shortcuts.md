## Everywhere

| Keys | What |
|---|---|
| ⌘K | Command palette (notes, `>` commands, `#` headings) |
| ⌘N / ⇧⌘N | New note / new notebook |
| ⌥⌘N | New API spec |
| ⇧⌘F | Search notes |
| ⇧⌘O | Go to heading |
| ⌃- / ⌃⇧- | Back / forward between notes |
| ⇧⌘A / ⇧⌘I / ⇧⌘T | All Notes / Inbox / Trash |
| ⌘1 / ⌘2 / ⌘3 | Editor only / split / preview only |
| ⌘\ | Show or hide the sidebar |
| ⇧⌘↵ | Focus mode |
| ⌘, | Settings |

## Claude

| Keys | What |
|---|---|
| ⌘J | Claude panel |
| ⌥⌘J | Coding layout |
| ⇧⌘J | Ask Claude to write at the cursor (/claude) |
| / (in the panel) | Slash commands |
| Esc (in the panel) | Stop Claude |
| Tab / Esc (in a note) | Accept / dismiss a grey suggestion |
| ⇧⌘M / ⌥⌘M | Comments panel / add a comment |

## The note

| Keys | What |
|---|---|
| ⌥⌘P | Pin / unpin |
| ⌥⌘T | Add a tag |
| ⌥⌘1 … ⌥⌘4, ⌥⌘0 | Status: Active, On hold, Completed, Dropped, none |
| ⌥⌘L | Copy a [[link]] to the note |
| ⌥⌘Y | Version history |
| ⇧⌘U | Insert image |
| ⇧⌘E / ⌘P | Export as PDF / print |
| ⇧⌘R | Reveal in Finder |
| ⌥⌘O | Open in a new window |

## Editing

| Keys | What |
|---|---|
| ⌘B / ⌘I / ⇧⌘X | Bold / italic / strikethrough |
| ⌘E / ⇧⌘H / ⌥⌘K | Inline code / highlight / link |
| ⌘↵ | Tick a checkbox |
| ⌥↑ / ⌥↓ | Move line up / down |
| ⇧⌥↓ | Duplicate line |
| ⇧⌘K | Delete line |
| ⌃J | Join lines |
| F5 / ⇧F5 | Sort lines A→Z / Z→A |
| ⌃0 | Normal text |
