## Settings (⌘,)

- **Appearance:** built-in light/dark, any **VS Code theme** on your Mac, "Same as VS Code", or import a theme file.
- **Editor:** font, size, line width, line numbers, Vim keys, spell check, link titles, scroll sync.
- **Claude:** a model per job, and the grey suggestions on/off ([[3. Writing with Claude]]).
- **Storage:** change the notes folder.

## Where your things live

- **Notes:** plain `.md` files in your notes folder (by default `Documents/VibeNotes`). Notebooks are folders. You can sync the folder between Macs (iCloud Drive, Dropbox, git…).
- **Pictures** you paste: a hidden `.assets` folder next to the note.
- **Projects:** a notebook with a "Project brief" note. Which code folder belongs to a project is set per Mac.
- **Per Mac only:** version history, Claude chats, settings, and your Atlassian sign-in (kept in the Mac's Keychain).

## Versions

- VibeNote has a **stable** version and an **experimental** one with the newest features.
- If something breaks, the newest stable version can be put back at any time; your notes and settings are not touched.
