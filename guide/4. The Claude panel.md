**⌘J** opens a chat with Claude next to your notes. It runs on your own Claude Code login. Claude sees the note you're viewing.

## Watching Claude work

- Its **thinking** appears live, then folds into "✻ Thought for 5s".
- Each **step** shows as it starts and ends with a short result: "Read app.js → 120 lines", "Edited notes.md → +3 −1". Click a step for details; edits show as a red/green diff.
- **To-do lists**, helper agents' progress, and a status line with time and tokens.
- **Esc** (or Stop) stops Claude.

## Mention things with @

- Type **@** in the chat box to pick a **project, note, Confluence page, API spec or diagram**. Claude is told exactly where it is, so it can read it.

## Permission

- The menu at the top says what Claude may do without asking: **Ask every time**, **Auto-approve edits**, or **Plan only**.
- Risky steps show an **Allow / Deny** card first. Questions show as a card with options.

## Slash commands — type **/**

- **/model** — switch model (or click the model button at the top) · **/effort** — how hard Claude thinks
- **/usage** — your plan limits (5-hour and weekly) and what this chat cost · **/context** — how full the chat's memory is
- **/clear** — new chat · **/chats** — past chats · **/mode** — permission mode · **/mcp** — connected tools · **/help**
- Plus all your Claude Code commands and skills (`/compact`, `/init`, `/code-review`…).

## Past chats

- The 🕘 button (or `/chats`) opens **Claude Chats**: every Claude Code chat you had in a folder — from Terminal, VS Code, the Claude app or **T3 Code**.
- **Continue in Claude panel** picks one up where it left off (as a copy — the original stays as it was). **Save as note** keeps the conversation as a note.

## Linking code

- Link a notebook or project to a code folder (panel ⋯ → Link a Code Folder) and Claude can read and change the code, run commands and commit. See [[5. Projects and code]].
